Politique cookies

Traceurs et stockages réellement utilisés dans cette version

  • cwt-cart (localStorage, pas un cookie) : conserve le contenu du panier dans le navigateur pour garder les articles entre les pages. Aucun identifiant publicitaire ou profil de navigation n’est ajouté par ce stockage.

Cookies non nécessaires

Aucun outil publicitaire, pixel de suivi ou solution d’analyse d’audience n’a été trouvé dans le code du projet audité. Aucun cookie non essentiel n’est créé par le JavaScript propre au site. En conséquence, aucun bandeau « Tout accepter / Tout refuser » n’est ajouté dans cette version. Si de nouveaux services nécessitant un consentement sont ajoutés, la politique cookies et les choix proposés aux visiteurs seront adaptés.

Scripts et services tiers réellement présents

  • Google Fonts : les pages chargent les polices depuis fonts.googleapis.com et fonts.gstatic.com.
  • Bootstrap 5.3.3 via jsDelivr : les pages chargent une feuille de style et le script bootstrap.bundle.min.js depuis cdn.jsdelivr.net.
  • FormSubmit : aucun script FormSubmit n’est chargé pendant la simple navigation ; le service reçoit les données uniquement lorsqu’un utilisateur envoie le formulaire de commande personnalisée ou le formulaire de rétractation.

Ces connexions peuvent impliquer le traitement de données techniques, notamment l’adresse IP, selon le prestataire et l’hébergement. Les conditions de ces prestataires, leurs éventuels transferts hors UE et les garanties associées sont décrits dans la politique de confidentialité lorsqu’ils sont applicables.
